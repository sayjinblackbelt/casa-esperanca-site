# 🏗️ Institutional Site Prototype

[🇧🇷 Português](README.md) | 🇺🇸 English | [🇪🇸 Español](README.es.md)

> A static institutional website prototype developed in 2024 and rebuilt for study, experimentation, and front-end portfolio purposes.

## 📌 Context

This project emerged in **2024** from practical experience managing digital content and from the need to create an independent version of an institutional website for testing and experimentation.

The original implementation was associated with a WordPress environment. The version preserved in this repository was later rebuilt as a static project, making it possible to explore a simple architecture using **HTML, CSS, and JavaScript**.

This project represents an important stage in my web-development journey and remains as a historical and technical reference.

> **Note:** this repository is a demonstration prototype and does not represent the official website of any specific organization.
